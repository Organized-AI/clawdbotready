Troubleshooting

Dashboard won't load?
• Check if tunnel is running: lsof -i :18789
• Restart tunnel: Kill the ssh process and recreate it
• Verify Gateway is running in VM: ssh into VM and run openclaw gateway status
Connection refused?
• Make sure you're accessing localhost:18789 not 127.0.0.1:18789
• Check Gateway status in VM
• Look at Gateway logs: ~/.openclaw/logs/gateway.log
